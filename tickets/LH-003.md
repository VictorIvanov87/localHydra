Status: TODO
Depends on: LH-001
Owned area: pure backend routing module and routing tests

## Scope
Select a model from supplied inventory/profiles and task requirements. Keep provider transport and UI outside this module. Define an injectable requirements interface for a future local classifier.

## Definition of done
- [ ] Hard filters enforce installed/configured allowlist, declared modality/features, and conservative context fit including output reservation. Unknown fit is handled explicitly; no eligible candidate gives a structured error.
- [ ] Deterministic ranking supports declared task suitability and configurable latency/load penalties. Configured assumptions are not labeled measured quality.
- [ ] Sticky conversation preference and manual override work without bypassing eligibility. Reset removes stickiness.
- [ ] Decisions include candidate exclusions, score components, selected exact tag, policy version, and measured/configured/estimated provenance.
- [ ] Unit tests cover general, coding and reasoning requests; ties; empty inventory; unknown profiles; uncertain context; unavailable pinned model; overrides and resets.
- [ ] Identical inputs and policy yield identical decisions. Router never calls external inference or downloads models.
